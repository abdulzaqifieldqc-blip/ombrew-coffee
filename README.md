# OMBREW COFFEE

Starter menu digital untuk OMBREW COFFEE.

## Menjalankan di GitHub Codespaces

Project ini tidak membutuhkan framework atau instalasi dependency.

1. Upload semua file ke repository GitHub.
2. Buka repository → **Code → Codespaces → Create codespace on main**.
3. Di Codespaces, jalankan server sederhana:

```bash
python3 -m http.server 8080
```

4. Buka port **8080** lalu pilih **Open in Browser**.

## WhatsApp

Buka `app.js`, cari:

```js
const phone = "6280000000000";
```

Ganti dengan nomor WhatsApp OMBREW COFFEE dalam format internasional tanpa `+`.

Contoh Indonesia:

```js
const phone = "6281234567890";
```

## Menu

Semua menu saat ini menggunakan ukuran 14 oz dan harga sesuai data awal.
